Overview

Nouvelle Spaces is an architecture, interiors and 3D visualisation portfolio with a cinematic homepage and a private content manager.

Visitors move through architectural films, an animated gallery of 22 projects with 138 views and a fullscreen viewer. The studio edits projects, images, text, films and metadata itself, with drafts, publishing and version restore.

What it does

01

Cinematic homepage

Two architectural films, interactive sections and a studio logo entrance.

02

Project gallery

Category filters, a fullscreen viewer and responsive images.

03

Private CMS

Projects, image order, media uploads, page text, links and hero films.

04

Drafts & versions

Draft previews, publishing and restoring earlier versions.

05

Accessible by design

Keyboard navigation and reduced-motion support.

06

Inquiry forms

Forms prepare an email draft for visitors to review and send.

How it works

  1. Edit

    The studio updates content in the private admin.

  2. Preview

    Changes are saved as drafts and previewed before going live.

  3. Publish

    Published content is rendered by authenticated serverless routes.

  4. Deliver

    Media stays private in Vercel Blob and is served through a controlled endpoint.
